# Security

Report a vulnerability in private. Do not open a public issue.

Use [GitHub private vulnerability reporting](https://github.com/fbritoferreira/strapi/security/advisories/new), or email me@fbritoferreira.com. Include the version, what an attacker can do, and a way to reproduce it.

You should get a reply within 7 days. Only the latest release on npm is patched.
