Tuples, not throws

Every method answers [error, data, meta]. A failed request is a value you handle, not an exception you remember to catch.

Types from your schema

strapi-client generate reads a Strapi project or a running instance and writes the interfaces plus a registry, so collection uids are checked.

Params checked against the route

Each method accepts only the query params its Strapi route declares. fields and populate are told apart, and the result type follows the selection.

The rest of the API

Auth, users, uploads, custom and plugin routes from an OpenAPI document, and GraphQL, including operations that do not require writing a query.
